# Decision docs — the behavior-docs project

The **decision docs** for the behavior-docs project: the durable _how_ that combines with
the [behavior docs](../behavior/README.md) to produce the behavior-docs product
(`product = f(behavior docs, decision docs)` — the two-input model). These carry realization
decisions the behavior docs deliberately exclude: architecture, tooling, testing, tuning, and
governance.

Each decision is an ADR (Architecture Decision Record) with a status. Current records:

- **[0001](0001-governance-human-agent-roles.md)** — governance: who and what may author or
  change behavior docs, and what supervision applies. _(stub)_
- **[0002](0002-authoring-as-markdown-wiki.md)** — author behavior docs as a cross-linked
  markdown wiki. _(stub)_
