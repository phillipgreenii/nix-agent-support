# pg-claude-code-recorder metric catalogue: the Signals table's metric names (docket pg2-v77tsx,
# phase 7c). One line per series "<name> <type> <labels>", every name carrying the prefix
# pg_claude_code_recorder_ in the Prometheus exposition; a histogram is listed once under its base
# name (its _bucket, _sum and _count series are implied). Labels are bounded and enumerated; a
# per-file or per-session label is forbidden. Loop durations are in SECONDS in the metrics and in
# MILLISECONDS (duration_ms) in the matching log events. check-signals-registration.sh compares this file with
# the M* constants of internal/obs/obs.go and internal/parser/parser.go, so a metric added in Go
# without a line here (or the reverse) fails the flake check
# test-pg-claude-code-recorder-signals-registration.
#
# Enumerated label values:
#   reason (dropped_bytes_total)   file_vanished generation_restart copy_trimmed snapshot_missed removal_race
#   reason (held_conversations)    copy_offset_mismatch copy_tail_mismatch parse_behind file_unparsed torn_tail_too_long restore_conflict
#   reason (skipped_files_total)   quarantine_unavailable holder_found write_after_rename file_replaced
#                                  restore_conflict live_process registry_names_session no_archive unlink_failed
#   stage                          live quiet held settled removal_pending removed
#                                  (conversations_by_stage is as of the last settle tick, up to 60 s old)
#   loop (loop_runs_total)         settle_tick refresh_gauges wal_checkpoint
#   outcome (loop_runs_total)      ok error
#   state (control_inbox_state)    present gone never_loaded
#   outcome (end_reason_source_files_total)  ingested removed invalid
#   verb (control_requests_total)  submit interrupt run read ping other
#   outcome (control_requests_total)  ok rejected duplicate refused other
#   registry_present, exit_observed, clear_entry, exit_entry (conversation_end_total)  true false
#   client (requests_total)        a whitelisted client name, otherwise other
#   op (requests_total)            the registered operation name, otherwise unknown
#   source (torn_tail_age_seconds) the source name (about 10 values)
#   outcome (requests_total)       the wire outcome name
