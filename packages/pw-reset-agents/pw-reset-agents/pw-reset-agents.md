# pw-reset-agents

> Clear stale AI agent activity markers; delegates to `agent-activity-api clean`.
> Stale markers make waiters such as `pw-agent-activity` count finished sessions as still busy.
> More information: <https://github.com/phillipgreenii/phillipgreenii-nix-agent-support>.

- Clear every stale activity marker:

`pw-reset-agents`

- Show the option list this wrapper handles:

`pw-reset-agents --help`

- Show version information:

`pw-reset-agents --version`
