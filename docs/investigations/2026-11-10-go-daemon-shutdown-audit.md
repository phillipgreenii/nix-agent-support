# Go daemon shutdown audit (2026-11-10)

Audit of every Go process that handles signals or runs under launchd, against the "Shutdown
requirements" (S1 to S8) and the module `ExitTimeOut` rule in `docs/go-daemons.md` of the
`nix-repo-base` repository. Point-in-time snapshot; paths are relative to each package or module
root and line numbers refer to the code as read on 2026-11-10.

## Method

- Every `signal.Notify` / `signal.NotifyContext` call site in the workspace Go code was listed,
  and every launchd registration (`launchdServices.userAgents.*`, `launchd.daemons.*`) in the
  workspace nix modules was read.
- The module rule: no module except the `pg-router` one sets `serviceConfig.ExitTimeOut`
  (`rg ExitTimeOut` over all workspace `*.nix` finds only `darwin/modules/pg-router/default.nix:196`
  and its flake assertion). Every other daemon therefore runs with launchd's default (5 s, as
  recorded in the comment at `darwin/modules/pg-router/default.nix:167-175`).
- "Fails margin" means the worst-case shutdown the code allows is at or above the 5 s default, so
  launchd can SIGKILL a daemon that is still shutting down.

## Corrections to the pre-triage hint

- pg-connector github and issue-jira do not conform: no `ExitTimeOut`, and the drain can take 60 s.
- pg-keep-awake does not conform: no `ExitTimeOut`, and shutdown sits at the default.
- pg-router conforms on `ExitTimeOut` only; S5 (deadline watchdog) and S7 (shutdown events) are
  absent.
- pg-task-focus and pg-desk are worse than "equal to the default": about 8 s and 10 s.
- pg-osx-notifier needs a fix (5 s, equal to the default); pg-osx-bridge-api, display-class do not.
- pg-router-disk-watchdog is not a daemon.
- The five stateless exporters conform; no shared fix is needed.

## Suggested common change

For the daemons whose only gap is the margin, set `serviceConfig.ExitTimeOut = 15` in the module
(the same value the recorder plan uses; deadline plus 7 s stays under the 60 s cap). Daemons with
an unbounded wait (pa-monitor, host-activity, beads-exporter) first need that wait bounded.
